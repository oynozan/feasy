## Mezo contracts used

| Mezo contract | Used for |
| --- | --- |
| BorrowerOperations | Open, adjust, refinance, close and claim collateral |
| TroveManager | Debt, collateral, status, rate and Recovery Mode reads |
| PriceFeed | The BTC price for share pricing and swap limits |
| HintHelpers, SortedTroves | Insert hints, so large moves never walk the whole trove list |
| MUSD Savings Vault (sMUSD) | Deposit, withdraw, claim yield, value from the yield index |
| Mezo DEX Router | Harvests and fee buy-backs in the MUSD/BTC pool |
| veBTC | Create, grow and withdraw locks |
| Pools Voter | Vote, poke and reset |
| sMUSD gauge rewards | Fee and bribe rewards in MUSD |
| RewardsDistributor | The weekly BTC rebate |
| ChainFeeSplitter | `updatePeriod`, run by the keeper when Mezo has not |
